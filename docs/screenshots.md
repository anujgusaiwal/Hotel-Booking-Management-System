## 📸 Screenshot Guidelines

### Best Practices

1. **Resolution**: Use standard screen resolutions (1920x1080 recommended)
2. **Format**: PNG for UI screenshots, JPG for photos
3. **Quality**: High quality, clear text, readable
4. **Consistency**: Use same browser/device for similar screenshots
5. **Privacy**: Blur or remove sensitive data (real emails, phone numbers)
6. **Annotations**: Add arrows or highlights for important features (optional)

### Tools for Screenshots

- **Windows**: Snipping Tool, Windows + Shift + S
- **Mac**: Cmd + Shift + 4, Screenshot app
- **Browser Extensions**: Full Page Screen Capture
- **Design Tools**: Figma, Adobe XD (for mockups)
