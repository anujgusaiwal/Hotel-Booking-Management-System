# Project Overview - Hotel Booking Management System

## Short Version (for PPT slide):

**Hotel Booking Management System** is a full-stack web application that provides a complete solution for managing hotel room bookings. The system features separate portals for customers and administrators, enabling seamless booking experiences while giving hotel management complete control over rooms, reservations, and analytics.

---

## Detailed Version (for documentation):

### What is it?
A comprehensive hotel booking management platform that automates the entire reservation process from room browsing to booking confirmation.

### Key Highlights:
- **Dual User Interface**: Separate portals for customers and hotel administrators
- **Real-time Availability**: Live room availability tracking and booking management
- **Secure System**: JWT-based authentication with role-based access control
- **Complete Booking Flow**: From room search to PDF receipt generation
- **Admin Dashboard**: Comprehensive analytics and management tools

### Main Components:
1. **Customer Portal**: Browse rooms, make bookings, view history, download receipts
2. **Admin Portal**: Manage rooms, bookings, view analytics, track revenue
3. **RESTful API**: Secure backend with proper authentication and validation
4. **Database**: MySQL database with optimized schema for bookings and rooms

### Technology Stack:
- **Frontend**: React 18, Tailwind CSS, React Router
- **Backend**: Node.js, Express.js, MySQL
- **Security**: JWT, bcrypt password hashing
- **Features**: Dark mode, responsive design, PDF generation
